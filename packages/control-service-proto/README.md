# @tryopenbot/control-service-proto

Generated ConnectRPC and protobuf types for the owner-facing control service. The proto is intentionally empty while the UX-first control API is designed.

## Public API

The package re-exports generated symbols from `openbot.control.v1`. There are currently no messages, services, or functions to consume. Edit `proto/openbot/control/v1/control.proto` and run `pnpm contracts:generate`; never hand-edit `src/gen/`.
