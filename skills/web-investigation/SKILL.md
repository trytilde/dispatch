# Investigate on the web

Start with a precise research question and identify what would count as adequate evidence.

1. Prefer official and primary sources for factual or technical claims.
2. Use more than one independent source when the conclusion is disputed, consequential, or time-sensitive.
3. Separate the event date from the publication date for news.
4. Record the direct page URL and the exact claim it supports. Do not cite a search-results page.
5. Distinguish observed facts, source claims, and your own inference.
6. Summarize in your own words and quote only the minimum useful fragment.

If login, payment, consent, or an irreversible action is required, stop and ask the owner before proceeding.
